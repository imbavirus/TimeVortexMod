# Changelog - v1.0.7

## Capability Fixes and ComputerCraft Support

### Energy Cables (Interface)
- Restored Forge Energy exposure on the Vortex Interface for NeoForge 1.21.1.
- Cables from Mekanism, Pipez, Powah, and other FE providers can connect and charge the Interface again.

### Item Transfer
- Registered item handler capabilities for the Size Manipulator, Scanner, and Keypad so hoppers and item pipes can interact with their inventories.

### CC: Tweaked
- Finished Vortex Interface peripheral registration (`peripheral.wrap` type: `vortex_interface`).
- Computers can use the existing Lua API: power, throttle, coords, dimension, flight state, exterior sign, and related getters.
- Declared ComputerCraft as an optional dependency.

### Stability
- Fixed Scanner crashes when scanning outside the TARDIS dimension or without a nearby Interface.
- Fixed Scanner GUI data sync so exterior preview values reach the client.
- Hardened TARDIS entity lookups against invalid entity types.
- Guarded network/connection and bioscanner renderer edge cases that could crash with no players online.
